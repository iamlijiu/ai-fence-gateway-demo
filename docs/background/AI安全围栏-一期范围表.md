# AI安全围栏 — 一期范围表（建议稿）

> 编制依据：《AI安全围栏建设方案.docx》v2 中 1.3 系统设计目标、2.3.1 功能全景、2.3.2 功能详细描述
> 编制原则：
> 1. 一期 = 上行链路敏感数据完全管控（P0）+ 必要的支撑能力；
> 2. 存在矛盾处按"业务诉求 → 功能实现 → 运维可行性"自洽原则调和（详见 D1~D6 决策点）；
> 3. 凡标注【需确认】的行，需业务方/技术方拍板后定稿。

## 二、一期 / 二期 / 搁置 汇总

### 一期交付（P0 主链路 + 支撑）
- **主链路**：报文解析（Header/Body/嵌套/Prompt）→ 规则匹配（字段路径+正则、9 类敏感信息、scope、优先级）→ 敏感请求管控（掩码/替换/删除/拦截/重组）→ 异常降级（reject/passthrough）
- **支撑**：统一请求标识（提升 P0）、脱敏操作日志（提升 P0）、规则配置最小形态 + 热加载（≤1 秒）、基础监控与告警

### 二期交付（P1）
- 接入鉴权增强（统一流式/非流式地址、业务方/接口/模型识别）
- 一致占位符 / 返回后还原（机制评审通过后）
- 下行链路全套：异步检测 → 内容安全检测（含高风险同步、安全改写）→ 结果反馈（3 模式）→ 违规记录与告警复核
- 规则管理完整版：灰度发布、回滚、版本化
- 管理后台完整版、完整多维统计报表
- "提示"降级模式、XML/gRPC 扩展

### 搁置（P2）
- 加密脱敏（依赖密钥管理方案）
- 多模态数据解析
- 完整统计报表

## 三、决策点清单（需确认后定稿）

| 编号 | 决策点 | 现状 | 建议 | 影响 |
|---|---|---|---|---|
| D1 | 一期规则配置的最小形态 | 文档矛盾（1.3 说不做规则配置化；2.3.1 规则配置 P0） | 一期做"预置规则集 + 基础 CRUD + 校验"，管理后台 UI 简化或复用现有平台 | 决定一期开发量；不做则规则无法运维 |
| D2 | 一期是否复用现有网关鉴权 | 接入鉴权模块标 P1 | 一期复用现有网关鉴权 + 仅生成请求标识；若设备之家要求一期统一流式/非流式地址，则接入鉴权提前到一期 | 决定是否需要新增鉴权开发 |
| D3 | "一致占位符 / 返回后还原"是否进一期 | v2 列为 P0（含在敏感请求管控模块） | **建议二期**：跨会话泄露、映射生命周期、流式还原等机制未设计，硬塞一期风险高 | 影响一期验收标准与风险敞口 |
| D4 | 9 类敏感信息清单确认 | 只提"9 类"未列清单 | 业务方+安全确认 9 类清单及默认规则/处置 | 决定初始规则集内容 |
| D5 | 分场景性能指标确认 | 需求"放宽为分场景"，2.4.1 仍是统一 50ms | 按场景出指标表（如设备之家高并发 vs 内部问答） | 决定压测达标口径 |
| D6 | 一期不做下行检测是否可接受 | 背景列为核心问题之一，但模块标 P1 | 与业务方确认一期仅上行管控、下行二期 | 决定一期交付边界 |

## 四、一期验收口径（非功能指标，一期生效部分）

| 指标 | 一期目标 | 说明 |
|---|---|---|
| 上行安全处理额外耗时 | < 50ms（P99） | 分场景指标确认后（D5）可能细化 |
| 单条规则匹配耗时 | ≤ 10ms | 与 1.3 规则管理模块口径统一（原 50ms 矛盾待清） |
| 规则变更生效时间 | ≤ 1 秒，无需重启 | 需 Apollo 推送机制设计（上轮 P0-1） |
| 重点敏感字段识别率 | ≥ 95% | 需定义测试集口径（上轮 P1-5） |
| 非敏感字段误修改率 | 0（抽检复核） | "0"按可测量口径执行（上轮 P1-1） |
| 已命中敏感数据处置成功率 | ≥ 99.9% | — |
| 降级策略执行正确率 | 按配置执行（抽检） | 原"100%"口径调整（上轮 P1-1） |
| 脱敏模块可用性 | ≥ 99.9% | — |
| 故障恢复时间 | ≤ 30 分钟 | 需补充开关/回滚预案（上轮 P0-7） |
| 请求标识生成率 / 传递完整率 | 100% / ≥ 99.9% | 一期日志关联基础 |
| 规则灰度手段 | 按业务方 scope + 总开关 + 旁路观察模式 | 替代灰度发布（二期再做正式灰度） |

## 五、配套待办（随一期范围表一并落实）

1. 上轮 P0 未决项需在一期设计阶段补齐：规则存储主从与热加载机制（P0-1）、异常降级执行载体与旁路观察模式（P0-7）、密钥管理（P0-5，影响加密脱敏与模型 API Key）；
2. 一期规则最小形态确定后，同步更新 2.3.2 规则 JSON 示例（补 disposition 字段）与 desensitization_rule 表（上轮 N2/P0-6）；
3. 一期验收需配套：9 类敏感信息测试集、压测方案（报文规模 × 规则集规模）、回归测试（不影响原业务）。
